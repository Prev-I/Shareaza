# previ.7 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship 2.7.11.2 (`v2.7.11.2-previ.7`) with the eleven fixes the owner approved on 2026-11-09.

**Architecture:** Two pull requests into `main`. A (`prev-i/previ7`, which holds the design) carries Tasks 1–11; B (`prev-i/version-2.7.11.2`) carries Task 13 after A merges. The Markdown-to-text logic lives in a new MFC-free file so it can be compiled and tested locally with g++.

**Tech Stack:** C++/MFC (v143), Inno Setup 6, GitHub Actions, Windows PowerShell 5.1, MSBuild.

**Spec:** `docs/superpowers/specs/2026-11-09-previ7-design.md`

## Global Constraints

- **Testing.** No Windows build or harness here. Each task's test is a check script in the plan workspace, run before the change (it must fail) and after it (it must pass). The release-notes helper (Task 4) also gets a real unit test compiled with g++. CI's MSBuild and the oracles are the real gate (Task 12).
- **Release macro.** `RELEASE_BUILD=1` comes from the `CL` environment variable, never from `vc143/ReleaseBuild.props` (it imports `WindowsXP.props`). ISCC never gets `RELEASE_BUILD`.
- **Release notes:** no `%`, and a plain first paragraph.
- **The upgrade window:** five controls in today's order and types (`Static, Static, Button, Button, Button`).
- **New settings:** `VersionCheck.UpgradeNotesURL` (string, default empty) and `Discovery.DefaultsVersion` (DWORD, default 0). `SMART_VERSION` stays 62.
- **Version:** 2.7.11.2.
- **Commits** end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **Messages and docs** describe changes by class and function only. The reviewer checks trigger disclosure as a named item.
- **After handing a pull request to the owner, push nothing more to it.**

## Review Focus

1. **A release body with only Markdown, or empty.** The summary must never be empty garbage or contain a raw `**`, `[`, `](`, `#` or `<`. Owned by Task 4's unit test.
2. **A 400+ character first paragraph, or one with a surrogate pair (emoji) at the cut.** The cut must not split a pair or a word. Owned by Task 4.
3. **An existing install whose `Discovery.dat` holds a query-string address, or a blocked copy of an unbanned cache.** It is dropped or unblocked once and saved. Owned by Tasks 7 and 9.
4. **A user who already has a saved bar layout.** It must be left exactly as it is. Owned by Task 10.
5. **The installer upgrading over previ.6 with the update check on.** The check stays on and a stale offer is cleared. Owned by Task 6.
