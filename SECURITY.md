# Security policy

## Reporting a vulnerability

Please report a vulnerability privately. Do not open an issue for it.

1. Open the [Security tab](https://github.com/Prev-I/Shareaza/security) of this repository.
2. Choose **Report a vulnerability**. This is GitHub's private vulnerability reporting.
3. Describe what you found and how you found it.

Only the maintainer can read a private report.

## Supported versions

Fixes go into the latest `previ.N` release only. Older releases are not patched. Update to the
newest release on the [Releases](https://github.com/Prev-I/Shareaza/releases) page.

This is a personal fork of Shareaza, not the original project. A problem that also exists in the
original code is fixed here, if at all, as time allows.
